💻 Code Sandbox MVP

Single-host, multi-language code execution sandbox. The Go API server accepts execution jobs over HTTP, runs each one in a locked-down Docker container, and exposes async poll-based results.

network: none read-only rootfs non-root uid 65532 no-new-privs memory / cpu / pids limits

What the API does

Submit source files for one of 7 languages, poll until the job reaches a terminal state, then read stdout / stderr. One docker run --rm per execution; workspaces are deleted after the run. Job records persist as JSON under DATA_DIR.

Endpoints

Method & pathDescription
GET /healthzHealth check → {"ok": true}. Always open, no auth.
GET /v1/languagesList supported languages + runner images.
POST /v1/executionsSubmit a job → 202 {id, status: queued}. Body: {language, files[], entrypoint, stdin?, limits?}
GET /v1/executions/:idPoll job. status: queued|running|succeeded|failed|timeout|oom|cancelled, plus exit_code, stdout, stderr, usage.wall_ms.
DELETE /v1/executions/:idCancel a queued job immediately; interrupt a running one.

Validation & limits

  • files: 1–20 files, ≤512KB total. Repo-relative paths only (no absolute, no .., no backslashes, max 5 levels).
  • entrypoint must match one entry in files[].
  • limits (all optional): timeout_ms 1–120000 (default 10000), memory_mb 64–1024 (default 256), output_kb 1–1024 (default 256).
  • Compiled languages (Go/Java/Rust/Swift) are slow on a cold cache — use e.g. {"timeout_ms":90000,"memory_mb":512}. Kotlin needs {"timeout_ms":120000,"memory_mb":1024}.
  • Rate limits per IP: POST /v1/executions 10/min, reads 300/min → 429.
  • Optional static key: send X-API-Key or Authorization: Bearer when the server sets API_KEY.

curl example

curl -s -X POST localhost:8080/v1/executions \
  -H 'Content-Type: application/json' \
  -d '{"language":"python",
       "files":[{"path":"main.py","content":"print(42)"}],
       "entrypoint":"main.py"}'
